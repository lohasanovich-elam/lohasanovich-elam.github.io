FROND FROLIC

Project Role: Programmer

Development Time: 4 Weeks

Project Runtime: September 2025 - October 2025

SYNOPSIS:

'FROND FROLIC' has you in an Endless Runner where you sweep the endless leaves of the serene autumn forest. This strange scarecrow jumps around, avoiding dangers, whilst trying to sweep the leaves of the forest at fall. It's unclear wether this is for fun or it has some larger goal but it really enjoys sweeping nonetheless. This game mostly plays out by timing your jumps and adapting to the procedurally generated parts of the stage, a very simple gameplay loop to be had.

Despite how obviously simple this game is, it was my first introduction to Unity 2D programming and so the core concepts within it allowed me to grasp the engine and C# programming. The quick time-span of the project gave me some struggle but nothing I wasn't too unfamiliar with, likewise variables and methods from my knowledge of Python programming.

Being introducted to so many core concepts through an 'endless runner' project allowed me to gain a better idea of how 2D Game environments run through most development workspaces. Figuring out more concepts within Unity was still challenging after this, however I began to piece these together much more in future projects. Overall, this project served as a solid introduction to proper game development in Unity.
